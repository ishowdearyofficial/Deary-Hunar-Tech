01 — THE SOFTWARE

Meet the operating system.

Think of an operating system as the helpful manager between you, your apps, and your computer’s hardware.

▤01.1

What is an OS?

The main software that manages your computer and gives you a way to control it.

See how it works +

An OS coordinates apps and hardware, handles files, and gives you an interface — like a desktop, menus, or a terminal. Windows, macOS, and Linux are all operating systems.

▦01.2

The interface

The buttons, windows, menus, and icons that let you interact with your device.

See how it works +

A graphical interface (GUI) lets you point, click, and tap. Some OS tools also offer a command line, where you type instructions directly.

▧01.3

Apps & programs

Extra software for the things you want to do, like write, browse, draw, or play.

See how it works +

The OS gives apps a safe, consistent way to use the computer’s memory, processor, screen, and other resources. You choose which apps to install.

02 — THE HARDWARE

What’s inside the box?

These physical parts work as a team. Open a card to get to know each component.

▦02.1

CPU — the processor

The CPU carries out instructions and calculations — it’s a bit like the computer’s coordinator.

See how it works +

When you open an app or solve a problem, the CPU processes instructions incredibly quickly. More CPU cores can handle more work at once.

▤02.2

RAM — working memory

RAM holds the information your computer is using right now, so it’s easy to reach.

See how it works +

More RAM can help when you have lots of apps or browser tabs open. RAM is temporary: its contents clear when the computer turns off.

▱02.3

Storage — keep your files

An SSD or hard drive stores your apps, documents, photos, and operating system.

See how it works +

Unlike RAM, storage keeps its contents when the computer is off. SSDs are typically faster; hard drives can offer lots of space at a lower cost.

⌘02.4

Motherboard — the connector

The main board that lets the computer’s components communicate with each other.

See how it works +

The CPU, RAM, storage, and other parts connect to the motherboard. Its pathways carry data and power throughout the system.

▧02.5

GPU — the graphics maker

The GPU creates the images and video you see on your screen.

See how it works +

A GPU can be built into the CPU or be a separate graphics card. Powerful dedicated GPUs are useful for 3D games, video editing, and design.

⌨02.6

Input & output

Devices that help you send information to the computer and receive it back.

See how it works +

A keyboard, mouse, and microphone are input devices. A monitor, speakers, and printer are output devices. Some devices, like touchscreens, do both.

03 — THE INTELLIGENCE

Get to know artificial intelligence.

AI is software designed to do tasks that usually need human-like skills. Here are a few useful ideas to know.

✳03.1

What is AI?

AI describes computer systems that can recognize patterns and help with specific tasks.

See how it works +

AI systems use rules or learned patterns to make predictions, sort information, recognize speech, or recommend what to watch. They do not think or understand exactly like people.

▤03.2

Machine learning

A way to build AI by letting a computer learn patterns from examples.

See how it works +

A machine-learning model is trained on data. It uses patterns from those examples to make a prediction on new information, and its results depend on the quality of its training data.

✎03.3

Generative AI

Tools that can create new text, images, audio, or code based on a prompt.

Use it thoughtfully +

Generative AI can be useful for brainstorming and explanations, but it can also produce convincing mistakes. Check important facts and avoid sharing private information.
